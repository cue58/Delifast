# Architecture initiale

L’application utilise l’App Router de Next.js sous `src/app/`. Le code partagé est organisé sous `src/components/`, `src/features/`, `src/lib/`, `src/hooks/` et `src/types/`. La page d’accueil actuelle est provisoire et n’implémente aucun parcours métier.

Les services Supabase et les modules métier seront ajoutés dans des étapes dédiées; aucun client ni service distant n’est configuré à ce stade.
